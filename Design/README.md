# App icon source

AppIcon-Master.png is the approved 2048-pixel Moonflower blue bloom from the
v0.1.0 refinement gallery. It contains no text or promotional framing.
MakeIcons.swift applies a padded rounded-square mask and native downsampling
to generate the macOS AppIcon catalog. Run it from the repository root using
Swift. Its review contact sheet is written outside the repository.

The master is an editable raster source. It is preserved independently of the
size variants so future framing adjustments do not require changing bloom-v1.
